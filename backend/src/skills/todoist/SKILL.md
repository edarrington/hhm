# Household Todoist Skill

## Index
Todoist: manage household tasks, organize projects, set due dates, track task progress.

## Base
# Task Management Operations

- Treat tasks like helping the household stay organized, not managing a database.
- Create tasks that are clear and actionable for household members.
- When capturing tasks from conversation, save relevant context and due dates.
- Respect household task organization conventions (projects, labels, priorities).

## Pack
## Household Todoist Tools

You're helping the household organize and track their shared tasks.

### Creating Tasks
1. Ask "What needs to be done?" to understand the task.
2. Ask "When does this need to be done?" to set the due date.
3. Ask "Which project?" to organize it with related tasks.
4. Confirm before creating: "So I'll add 'X' to the Y project, due Z. Sound good?"

### Finding Tasks
- Summarize by project or priority instead of listing raw data.
- Help the household understand what's urgent vs. routine.
- Suggest task grouping if related items exist.

### Task Capture from Conversation
When household members mention tasks casually ("We need groceries", "Fix the fence"), capture them:
- Ask if they want to add it to Todoist
- Set reasonable due dates based on urgency
- Assign to appropriate project

### Household Task Conventions
- Common projects: shopping, household maintenance, meal planning, family projects
- Priority levels: high, medium, low; map conversation context to appropriate level
- Recurring tasks: weekly shopping, monthly bill payment, seasonal maintenance
- Task delegation: save who typically handles what task
